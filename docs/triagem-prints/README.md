# Triagem dos prints brutos (jul-ago 2026)

Catálogos de transcrição dos 926 screenshots que estavam em `img_game/`
(pasta local, fora do git). Cada entrada registra a tela, o assunto, a
transcrição fiel dos textos/números e a classificação
(NOVO / já-documentado / duplicado / baixo-valor).

- `catalog_00-05.md`: primeira leva (151 prints de 22-24 ago.)
- `ncat_00-30.md`: leva histórica (775 prints de 27 jul. a 21 ago.)

Todo o conteúdo de alto valor foi incorporado aos módulos em `app/data/`.
O que ficou de fora de propósito: lojas, pacotes de eventos e recompensas
de arena (conteúdo efêmero) — as transcrições ficam aqui caso um dia valham
uma seção. Os prints escolhidos como evidência (~150) foram comprimidos e
renomeados em `public/screenshots/`.
